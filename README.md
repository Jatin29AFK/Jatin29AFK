### 3. HireFit – AI Resume–JD Matcher

An AI-powered resume and job description matcher designed to analyze role fit, ATS readiness, skill gaps, and safer resume optimization.

**Key Highlights:**
- Built using **FastAPI, React, Vite, Tailwind CSS, Python, NLP pipelines, and Gemini API**
- Performs resume-to-JD matching, semantic comparison, ATS scoring, and skill gap analysis
- Validates whether skills are supported by evidence in the resume
- Simulates shortlist risk from a recruiter’s perspective
- Generates safer optimized resume drafts without inventing unsupported claims
- Supports multi-JD comparison and recruiter-facing recommendations

**Tech Stack:** FastAPI, React, Python, NLP, Gemini API, TF-IDF, Cosine Similarity, Resume Parsing
